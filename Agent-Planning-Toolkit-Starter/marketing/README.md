# Marketing Campaign System

This folder defines the audience strategy for campaign work without exposing private methods.

## Purpose

- Identify target buyer segments.
- Translate each segment into user stories and offer language.
- Provide an expert specification so an agent can build campaign drafts reliably.
- Define model-selection criteria for different campaign tasks.

## Files

- `buyer-profiles.md`
- `user-stories.md`
- `expert-role-campaign-strategist.md`
- `model-selection-guide.md`
- `agent-prompt-template.md`

## Working rule

All campaign artefacts should stay outcome-first:

- describe pains, desired outcomes, and trust signals,
- avoid revealing internal methods, private IP, or sensitive client detail.
