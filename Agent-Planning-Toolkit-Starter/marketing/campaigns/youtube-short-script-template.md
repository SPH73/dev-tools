# YouTube Short Script Template (Configurable)

Use this scaffold to produce a 30-60 second short.

## Inputs

- Segment:
- Core pain:
- Outcome promise:
- Proof artefact:
- CTA keyword:

## Script structure

### 1) Hook (0-5s)

`If you are <segment> and <pain>, this is for you.`

### 2) Reframe (5-15s)

`The real problem is not <surface issue>. The real problem is <core issue>.`

### 3) Outcome (15-30s)

`What you need is <outcome promise>, so you can <business result>.`

### 4) Proof (30-45s)

`I built this in public and you can verify it in <proof artefact>.`

### 5) CTA (45-60s)

`If you want this for your project, reply <CTA keyword>.`

## Voice rules

- Short, plain sentences.
- One promise per short.
- Outcome-first language only.
- No private method or sensitive details.
