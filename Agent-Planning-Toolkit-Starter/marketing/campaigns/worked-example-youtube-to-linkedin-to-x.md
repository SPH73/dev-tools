# Worked Example: YouTube -> LinkedIn -> X

This example shows one message scaffold adapted per channel.

## Input block

- Segment: non-coding but commercially savvy founders
- Core pain: too many AI options, no clear execution sequence
- Outcome promise: execution-ready plan with clear priorities
- Proof artefact: `PORTFOLIO-EVIDENCE.md`
- CTA keyword: `PLAN`

## 1) YouTube Short script (30-60s)

Hook:

If you are commercially savvy but non-coding, this is for you.

Reframe:

The real problem is not ideas. The real problem is sequence.

Outcome:

You need an execution-ready plan with clear priorities so you stop stalling and start shipping.

Proof:

I built this in public and you can verify it in `PORTFOLIO-EVIDENCE.md`.

CTA:

If you want this for your project, reply `PLAN`.

## 2) LinkedIn post (derived from same core)

If you are commercially strong but non-coding, AI can feel noisy fast.

The issue is rarely ideas. It is execution sequence.

What works is simple: clear priorities, practical next steps, and confidence in what to do now.

I have mapped claim to proof publicly so outcomes can be verified.

If this fits your context, reply `PLAN`.

## 3) X posts (all <=280 chars)

### Signal

Commercially savvy but non-coding? AI noise is not the problem. Sequence is.  
Bring your idea. Leave with an execution-ready plan. Reply `PLAN`.

### Proof

I stopped pitching AI and started shipping evidence.  
Claim -> proof is public in my repo index.  
Reply `PLAN` if you want the same model for your project.

### CTA

If you have ideas and budget but no clear build sequence, message `PLAN`.  
I help non-coding founders leave with execution-ready priorities.
