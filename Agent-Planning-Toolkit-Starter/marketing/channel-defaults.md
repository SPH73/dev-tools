# Channel Defaults

Use these defaults for consistent campaign production by humans and agents.

## LinkedIn defaults

- Goal: clarity + trust + qualified response.
- Format: 8-16 short lines.
- Tone: professional, direct, practical.
- Structure:
  1. Hook line
  2. Pain reframe
  3. Outcome promise
  4. Proof cue
  5. CTA line
- CTA style: one keyword reply (`PLAN`, `CLARITY`, `SPRINT`).
- Post length target: 600-1200 characters.

## X defaults

- Goal: concise signal and reply trigger.
- Character limit: 280 characters max.
- Derivation rule: derive from YouTube short core message.
- Structure:
  1. Hook
  2. Outcome promise
  3. CTA keyword
- Hashtags: optional, maximum 2.
- Style: one idea per post, no filler.

## YouTube Shorts defaults

- Goal: fast trust and memorability.
- Duration: 30-60 seconds.
- Script structure:
  1. Hook
  2. Reframe
  3. Outcome
  4. Proof
  5. CTA
- Caption style: one-line summary + CTA.
- Audio pacing: short, punchy sentences.

## Cross-channel consistency rules

- One promise per asset.
- Keep same core message across channels.
- Do not expose private methods or IP.
- Anchor claims to available proof artefacts.
