# Model Selection Guide for Campaign Work

Use this guide to choose the right model profile for each campaign task.

## Selection principles

- Use higher-reasoning models for positioning and strategy synthesis.
- Use faster models for high-volume draft generation and variations.
- Use stable, instruction-following models for formatting and contract checks.

## Task-to-model profile mapping

## 1) Strategy and positioning

Use when:

- choosing target segment priority,
- framing offer positioning,
- designing campaign architecture.

Preferred profile:

- high reasoning depth, medium speed.

## 2) Copy variation and hooks

Use when:

- generating multiple post angles,
- producing CTA variants,
- adapting one message across channels.

Preferred profile:

- medium reasoning, high speed.

## 3) Quality and compliance pass

Use when:

- checking message against guardrails,
- enforcing output contract structure,
- validating no method/IP disclosure.

Preferred profile:

- strong instruction-following, deterministic output.

## 4) Multi-step campaign packages

Use when:

- producing full package (strategy + drafts + metrics plan),
- iterating across feedback loops.

Preferred profile:

- higher context capacity with consistent instruction retention.

## Practical decision flow

1. Start with strategy profile for core positioning.
2. Switch to speed profile for variation generation.
3. Run compliance profile as final pass before publish.
