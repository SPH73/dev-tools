# Contributing

Thanks for helping improve this toolkit.

## Scope

This project focuses on repeatable, high-quality planning workflows for AI-assisted delivery:

- intake schema design,
- prompt templates,
- output contracts,
- review/checklist standards.

## Ways to contribute

- Report issues with schema clarity or missing fields.
- Improve prompt quality and output consistency.
- Add examples from real-world planning runs.
- Improve docs, onboarding, and quickstart guidance.

## Contribution flow

1. Open an issue describing the problem or proposal.
2. Keep PRs scoped to one concern.
3. Include before/after examples when changing templates or contracts.
4. Update relevant docs when changing structure.
