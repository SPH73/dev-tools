# Output Contract: CI/CD Plan v1

Generated plans MUST include these exact headings:

1. `## Current State`
2. `## Target State`
3. `## Options Considered`
4. `## Recommended Approach`
5. `## Execution Plan`
6. `## Risks and Mitigations`
7. `## Validation and Success Metrics`
8. `## First Implementation Checklist`

## Minimum quality checks

- `Options Considered` includes at least 2 options.
- `Execution Plan` includes `Now`, `Next`, and `Later`.
- `Risks and Mitigations` includes at least 3 risks with owner.
- `First Implementation Checklist` has 8-20 concrete tasks.
