# Operator Playbook: Agent-Orchestrated Delivery

## Core loop

1. Define goal and success criteria.
2. Provide structured intake.
3. Run agent with output contract.
4. Review against rubric.
5. Accept, refine, or re-run.
6. Record decision and next action.

## Escalate to human decision

Escalate immediately when:

- a gating decision is required,
- persistent failures remain after one retry,
- scope drift appears,
- external dependencies block progress,
- contradictory requirements are detected.

## Discipline rules

- Keep ungated and gated work separate.
- Never accept output without contract checks.
- Keep decisions and known gaps explicit.
