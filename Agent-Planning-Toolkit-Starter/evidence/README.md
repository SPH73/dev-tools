# Evidence Capture Loop

Capture proof while the work is happening so social proof costs time only once.

## Audience focus

Primary audience for these case studies:

- non-techy savvy founders

## Why this works

- You document outcomes once and reuse them in posts, proposals, and calls.
- You build public trust without revealing private methods.
- You create proof-of-capability as a natural by-product of delivery.

## What to capture each run

1. Starting state (what was blocked).
2. Intent (what they wanted to achieve).
3. Constraints (time, team, budget, risk).
4. Outcome artefacts delivered.
5. Measurable impact (speed, clarity, confidence, risk reduction).
6. Client quote (or anonymised paraphrase).
