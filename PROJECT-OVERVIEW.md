## Stage definitions

- `Draft`: early shaping, not yet public-ready.
- `Public starter`: usable in public with core docs and structure.
- `Active`: currently being iterated and maintained.
- `Stable`: broadly usable, changes are mostly incremental.
- `Archived`: no active iteration, retained for reference.

## Per-project update checklist

When any project advances stage or major scope:

1. Update the row in this file.
2. Add/refresh a case-study or evidence artefact.
3. Update `CHANGELOG.md` if release-worthy.
4. Add a short note under `releases/` if publicly shipped.
