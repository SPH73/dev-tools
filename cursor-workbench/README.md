# Cursor Workbench (Public Staging)

This folder is the staging area for share-safe drafting artefacts before they are promoted into product folders.

## Purpose

- Hold candidate files copied from private drafting contexts only after a share-safe check.
- Keep promotion workflow explicit and reversible.
- Avoid mixing raw private drafts directly into published toolkit folders.

## How to use

1. Copy a share-safe candidate here from private drafting.
2. Review for naming, scope, and sensitivity.
3. Promote into target folder (for example: `Agent-Planning-Toolkit-Starter/evidence/`).
4. Remove or archive stale staging files once promoted.

## Rules

- No secrets, private client data, or private IP details.
- Keep files outcome-oriented and publication-safe.
- Do not treat this as final home; it is a staging area.
