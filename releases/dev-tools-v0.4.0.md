# dev-tools v0.4.0

Date: 2026-08-26

## What changed

- Added a portfolio-level `PROJECT-OVERVIEW.md` tracker and linked it from root README.
- Added explicit public/private sync governance:
  - `SYNC-RULES.md`
  - `cursor-workbench/README.md`
- Added first public case-study and post-draft artefacts in toolkit evidence.
- Added employer/client-oriented case study for capability proof.
- Strengthened CI reliability signals:
  - Node 18 and 20 matrix for `Table-Formatter`,
  - workflow dispatch and concurrency controls,
  - JSON schema and sample intake contract checks.

## Why this release matters

This release moves the repository from a toolkit collection to a public, inspectable execution system.
It improves reputation signals by pairing delivery output with governance discipline and test visibility.

## Collaboration model used

AI-assisted execution with human-owned decision authority.  
Scope, safety boundaries, and publication decisions remained human-led; automation handled structured implementation and verification.

## Audience fit

This release sharpens support for non-coding but commercially savvy founders who need execution clarity, not tooling complexity.
