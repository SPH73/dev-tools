# Provenance Notes

This folder stores release-level evidence of how work was produced.

## Purpose

Each note captures:

- what shipped,
- how AI collaboration was used,
- what validation was run,
- who held final decision authority.

## File naming

Use:

`YYYY-MM-DD-<release-or-scope>.md`

Example:

`2026-08-26-dev-tools-v0.3.0.md`

## Minimum note structure

- Scope
- AI collaboration summary
- Human decisions
- Validation evidence
- Risk and follow-up
